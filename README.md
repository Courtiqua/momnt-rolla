# MOMNT ROLLA — Smart Find V3
Product flow: choose → index → search → shortlist → montage.

This phone-first prototype:
- Lets the user explicitly choose photos/videos
- Builds a searchable local collection
- Searches filenames/available metadata immediately
- Provides quick-search chips
- Lets the user shortlist media for a montage
- Keeps the locked pink/lavender/ocean visual identity

Next engineering layer: on-device/server visual tagging of the actual image/video content, plus location/date indexing, followed by montage rendering.
